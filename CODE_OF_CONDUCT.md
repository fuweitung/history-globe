# Code of conduct

History Globe is about difficult as well as inspiring parts of the past. We want everyone, from students to historians, to feel able to help.

## What we ask

- **Be kind and respectful.** Disagree with ideas and evidence, never with people.
- **Be fair about disputed history.** Where scholars or governments disagree, show each side with sources. Do not use this project to push a political or national agenda.
- **Use sources.** Back up a correction with a source; say honestly when you have not read it.
- **No harassment, hate or personal attacks,** including towards any people, nations, religions or ethnic groups.
- **Respect privacy.** Do not share other people's personal details. The project does not name living people.

## If something goes wrong

Tell us through GitHub (a private report under the **Security** tab works for conduct problems too, or comment on the issue and ask a maintainer to look). Maintainers may edit or remove comments, close issues or pull requests, and block people who repeatedly break these rules.

This code applies in the repository, its issues and pull requests, and any official project account.
