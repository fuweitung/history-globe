# Security policy

History Globe is a static website: it has no accounts, no database and no server code. Even so, if you find a security problem (for example a way to inject script into a page, or a leaked secret), please tell us privately first.

## How to report

Use GitHub's private reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not post security problems in a public issue.

Please include what you found, where, and the steps to reproduce it.

## What to expect

We are two volunteers, so replies can take a few days. We will acknowledge your report, fix real problems as quickly as we can, and credit you in the fix if you wish.

## Not a security issue

Factual mistakes in the history content are very welcome, but they go through the **Report a mistake** link in the app or a normal issue (see [CONTRIBUTING.md](CONTRIBUTING.md)).
